# check-the-core-keeper-mod-in-game

Drafted from a working procedure.

1. Check the Core Keeper mod in-game by reading Player.log at %USERPROFILE%\AppData\LocalLow\Pugstorm\Core Keeper\Player.log, not the screen. The mod only writes '[JadeHud]' lines, and a successful load shows 'loaded mod JadeHud' and 'Successfully compiled JadeHud'. Tell the user this path up front.
