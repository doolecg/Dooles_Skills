# to-see-how-another-core-keeper

Drafted from a working procedure.

1. To see how another Core Keeper mod works, read its decompiled sources in the Steam workshop folder at steamapps/workshop/content/1621690/<id>/Scripts (for Item Browser, id 3673289586, look under ItemBrowserPackage/Scripts). Its HighlightContainersSystem.cs shows that the client already knows chest contents, which a Jade-style locate feature could reuse.
