# steam-workshop-and-mod-io-uploads-are

Drafted from a working procedure.

1. Steam Workshop and mod.io uploads are built into the Core Keeper Mod SDK and run from the PugMod window in Unity, not from the command line. Uploads need the user's logged-in accounts, and the mod.io tab is compiled only under PUG_USE_MODIO. Publishing is outward-facing, so the user presses the upload button.
