# to-view-a-generated-html-file

Drafted from a working procedure.

1. To view a generated HTML file in the Operant browser, navigate to the local URL the browser serves for that file. The file: scheme is blocked, and injecting a copy with browser_evaluate drifts from the real file, so use it only as a last resort.
