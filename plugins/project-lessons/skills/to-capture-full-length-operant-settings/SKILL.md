# to-capture-full-length-operant-settings

Drafted from a working procedure.

1. To capture full-length Operant settings and Memory screenshots, run `npm run build` first, then run a script outside the repo that launches the built app with throwaway data, seeds a project with lessons, grows the viewport to the tallest scrollable area, and saves each shot.
