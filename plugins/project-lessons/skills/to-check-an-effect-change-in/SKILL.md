# to-check-an-effect-change-in

Drafted from a working procedure.

1. To check an effect change in the running dev EffectCraft, send parameter sets over its control channel on port 9877 and render a PNG for each. Read the PNGs to confirm the visual result, because the tests do not show what the effect looks like.
