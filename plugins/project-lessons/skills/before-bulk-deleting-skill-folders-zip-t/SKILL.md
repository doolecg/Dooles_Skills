# before-bulk-deleting-skill-folders-zip-t

Drafted from a working procedure.

1. Before bulk-deleting skill folders, zip the whole skills folder to %TEMP% and confirm the zip lists the entries to be removed. When a skill is a junction or link to a folder elsewhere, remove only the link, never its target, and check that no remaining link is broken afterwards.
